Set `NEXT_PUBLIC_GA4_MEASUREMENT_ID=G-...` to the real GA4 web-stream ID in the web deployment environment, then rebuild. Without this value, analytics and the consent UI remain disabled.

For the repository's Docker/GitHub Actions deployment, set the repository Actions variable `NEXT_PUBLIC_GA4_MEASUREMENT_ID`; the workflow forwards it as a Docker build argument. A runtime-only environment change is insufficient because Next.js embeds this public value during compilation.

The localized landing consent control offers Allow/Decline and a persistent preferences button. No Google script loads before consent. Tracking runs only in production and only while the landing component is mounted. Revoking consent disables event collection. Existing Google cookies expire according to the stream's configuration; they are not used for further collection after opt-out.

In the GA4 web stream, disable Enhanced Measurement automatic events/history page changes: this integration explicitly sends landing page views and interaction events and is deliberately scoped to the public landing page. Do not install a second GA/GTM configuration for the same stream. Use Tag Assistant/DebugView to verify the deployment and mark `signup_cta_click` / `business_whatsapp_click` as key events if those are the desired conversion goals.

Events: `page_view`, `pricing_view`, `signup_cta_click`, `marketplace_view`, `marketplace_click`, `vendor_open`, `whatsapp_click`, `business_whatsapp_click`, and `landing_error`. Properties are limited to locale, section placement, sanitized landing URL/referrer origin, fixed error category, and campaign slugs. No guest details, phone numbers, messages, exception stacks, private URLs, or arbitrary link text are transmitted. Raw query strings are omitted. `utm_source`, `utm_medium`, and `utm_campaign` are accepted only as 1–80-character ASCII letters/digits/underscore/hyphen slugs (for example `summer_2026`); use those conventions in advertising links and never put personal data into campaign parameters.

`landing_error` counts JavaScript errors and unhandled rejections after consent. It is not a full crash-diagnostics service. Advertising pixels and session replay are not needed for this baseline and are not installed.

Reference: [GA4 explicit page views](https://developers.google.com/analytics/devguides/collection/ga4/views), [Google application structured data](https://developers.google.com/search/docs/appearance/structured-data/software-app).
