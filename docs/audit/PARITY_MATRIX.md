# Web ↔ Mobile Feature Parity Matrix

Every user-facing feature × web present × mobile present × differences noted. Identifies gaps where mobile is missing functionality that exists on web, and vice versa.

## Mobile-Admin Scope Decision

Peter (product owner) confirmed: **Mobile should have all web features EXCEPT template management UI.** Bulk operations, exports, ticket assignment, and all other admin features should be added to mobile.

## Known Gaps

### High Priority
- **Whitelabel Post-Approval Setup-Password:** Web has full setup-password flow after approval. Mobile: ABSENT. Status: Must be added in fix phase.
